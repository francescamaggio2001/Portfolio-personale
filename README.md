# Portfolio Personale | Francesca Maggio

Portfolio personale sviluppato come progetto pratico del percorso di formazione in UX/UI Design.

Il sito nasce con l'obiettivo di presentare il mio profilo professionale, le competenze acquisite e una selezione dei miei progetti creativi e digitali.

Il design combina un'identità visiva personale con un layout responsive, caratterizzato da una palette bordeaux e crema, tipografia decorativa e un'interfaccia essenziale e intuitiva.

## Tecnologie utilizzate

- HTML5 – Struttura semantica delle pagine.
- CSS3 – Stili, layout e animazioni.
- Sass (SCSS) – Organizzazione del codice CSS tramite variabili e annidamento dei selettori.
- Flexbox e CSS Grid – Gestione dei layout responsive.
- Bootstrap – Framework CSS per la gestione di componenti e layout.
- JavaScript – Gestione delle interazioni.
- EmailJS – Invio dei messaggi tramite il modulo di contatto.
- Git e GitHub – Versionamento e gestione del progetto.
- GitHub Pages – Pubblicazione online.

## Funzionalità e caratteristiche

- Design responsive, adattabile a desktop, tablet e smartphone.
- Navigazione tra le pagine Home, About Me, Projects e Contact Me.
- Presentazione dei progetti con collegamenti ai relativi elaborati.
- Animazioni ed effetti hover per migliorare l'esperienza di navigazione.
- Sezione dedicata alle competenze e al percorso formativo.
- Accesso al curriculum vitae in formato PDF.
- Modulo di contatto con validazione dei campi e messaggio di conferma.
- Utilizzo di elementi semantici e accorgimenti per l'accessibilità.
